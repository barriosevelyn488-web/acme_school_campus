# School Management System

hecho por Evelyn Barrios

Proyecto de clase para consultar información académica y descargar reportes en HTML. Los datos corresponden al esquema de estudiantes, profesores, cursos, horarios, inscripciones y temas.

## Reportes

- Estudiantes y profesores.
- Horarios por curso, con docente y aula.
- Estudiantes inscritos en cada curso.
- Temas de cada curso.

## Carpetas principales

- `public/`: página, estilos y JavaScript de la interfaz.
- `src/`: servidor Node.js, rutas, lógica de reportes y consultas SQL.
- `docs/`: instrucciones, arquitectura y esquema de la base de datos.

Para instalar y ejecutar la aplicación, sigue [la guía de inicio](docs/INICIO_RAPIDO.md).
